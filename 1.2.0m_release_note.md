# SwitchU fork 1.2.0m

The menu shows icons, avatars and text again on firmware 23 with Atmosphere
1.12.1.

Deploy the daemon and the menu together — `atmosphere/contents/…/exefs.nsp`
and `switch/SwitchU/bin/menu/main` are built as a pair. Only the menu's code changed
in this release, so the 1.2.0l daemon also works with this menu.

## A blank menu on firmware 23

The menu kept 24 MiB of its memory free as a safety margin and refused to
load any image that would eat into it. On firmware 23 with Atmosphere 1.12.1
the menu starts with only 9 to 12 MB free, so every image was refused and the
menu came up with no game icons, no avatars and no text. The margin is now
2 MiB, the same as upstream SwitchU, which still stops image loading before
memory runs out. When the menu does refuse an image, its log now shows how
much memory was used and how much there was in total.
